# Commit Counter Widget

Potrzebuję prosty projekt prostego widgetu na ekran główny Androida o wymiarach 2x1 razem z aplikacją, która służy tylko do personalizacji widgeta. Potrzebuję taki sam w pomyśle widget jak ten od Githuba z policzonymi commitami każdego dnia (chcę mierzyć swoją aktywność programistyczną). Podaj pomysły i zaplanuj jak to można jeszcze lepiej zwizualizować (liczbę commitów)
